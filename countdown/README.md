# 时序 · 计划倒计时

公开访问地址：https://ae-li.github.io/qieli/countdown/

无需账号，每位使用者的数据保存在自己的浏览器。支持创建、编辑、删除撤销、完成及恢复计划；分类、颜色、排序；JSON 备份与合并导入。已打开过的页面支持离线访问。

剩余至少 24 小时显示完整剩余天数；少于 24 小时显示小时（保留一位小数，不足 0.1 小时显示 `< 0.1`）；到期显示“已到期”。每 15 秒刷新，重新打开页面会立即重算。以设备时间为准，不提供后台通知。

直接发布本目录到静态网站即可，无需构建。手机可通过浏览器菜单添加到主屏幕。清除浏览器数据前请先导出备份。
